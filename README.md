# 🏥 Landing Page: MBA em Liderança, Gestão e Governança na Saúde (FACCAT)

Esta é uma Landing Page de alta performance desenvolvida para o lançamento do curso de **MBA em Liderança, Gestão e Governança na Saúde** das Faculdades FACCAT. O projeto utiliza uma arquitetura front-end moderna focada em conversão (CRO) e autoridade de marca no setor educacional de saúde.

## 🎯 O Projeto
Como docente proponente, projetei esta interface para apresentar uma formação executiva de 600 horas voltada a profissionais que buscam transicionar do nível assistencial para a liderança estratégica. A página foi estruturada para comunicar soluções para desafios reais do setor, como a complexidade da gestão hospitalar, segurança jurídica (LGPD) e alta performance de equipes.

---

## 🛠️ Excelência Técnica e Performance

Seguindo os mais altos padrões de desenvolvimento web, o projeto conta com:

* **Arquitetura Front-end**: One-page responsiva construída com HTML5, CSS3 e JavaScript (Vanilla).
* **Design System & Tipografia**: Implementação de tipografia fluida utilizando a função CSS `clamp()`, garantindo uma leitura confortável em qualquer dispositivo.
* **Otimização de Performance**: 
    * Imagens servidas em formato **WebP** e JPEGs otimizados.
    * Implementação de **Lazy Loading** (`loading="lazy"`) e decodificação assíncrona (`decoding="async"`).
* **Resiliência de Dados**: Formulário de captura com validação robusta e sistema de fallback offline para assegurar que nenhum lead seja perdido.

---

## 📈 Estratégias de Marketing e SEO

A interface foi otimizada para maximizar o engajamento e a indexação orgânica:

* **SEO Técnico**: Configuração completa de metadados (Open Graph e Twitter Cards) e estruturação de dados em **JSON-LD** para otimização em motores de busca.
* **Foco em Conversão (CRO)**: Botão flutuante de WhatsApp estrategicamente posicionado e sistema de captura automatizada de parâmetros UTM para rastreabilidade de campanhas.
* **Acessibilidade (a11y)**: Uso de tags semânticas e textos alternativos (ALT) otimizados para inclusão e melhor ranqueamento.

---

## 🎓 Sobre o MBA em Saúde (Diferenciais)

O projeto comunica visualmente os pilares de uma pós-graduação desenhada para a nova era da saúde:

* **Formação Robusta**: Carga horária de **600 horas**, com foco em resultados práticos.
* **Modelo Executivo**: Formato híbrido (Blended Learning) ideal para profissionais em atuação.
* **Grade Estratégica**: Governança Clínica e Corporativa, Compliance/LGPD, Telemedicina e Transformação Digital.
* **Corpo Docente de Elite**: Equipe composta por Mestres e Doutores com atuação em instituições de referência (FAMEMA, Unimed, entre outras).
